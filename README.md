# 坦克大战 (Battle City)

经典《坦克大战》的网页复刻版，使用纯 HTML5 Canvas + JavaScript 实现，零依赖，单文件，打开 `index.html` 即可游玩。

## 🎮 玩法

- 保卫你的基地（金色雄鹰）不被敌方坦克摧毁
- 击毁全部 20 辆敌方坦克即可过关，关卡循环、难度递增
- 基地被摧毁或生命耗尽则游戏结束

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` / `WASD` | 移动坦克 |
| `空格` / `J` | 开火 |
| `P` / `Esc` | 暂停 |
| `Enter` | 开始 / 重新开始 |

## ✨ 特色

- **5 种地形**：砖墙（可摧毁）、钢墙（仅强化子弹可摧毁）、水域（子弹可越过）、草丛（可藏身）、基地
- **4 种敌人**：普通坦克、快速坦克、强力坦克（子弹更快）、装甲坦克（4 点血）
- **4 种道具**：⭐ 火力强化（加速 + 双发 + 击穿钢墙）、🪖 护盾、💣 全屏炸弹、🛡️ 加命
- **3 张地图**循环，后期关卡敌人更快更多
- 复古像素画风、爆炸粒子特效、8-bit 风格音效（Web Audio 合成，无外部资源）

## 📁 本地运行

直接双击 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
# 或
npx serve .
```

## 🛠️ 技术实现

- 纯原生 JavaScript，无任何库/框架/图片/音频资源
- 26×26 半砖网格地图，AABB 碰撞检测 + 分轴移动（贴墙滑动）
- 子弹分段步进检测，防止高速穿透
- `requestAnimationFrame` 主循环，按时间步长缩放，兼容高刷新率屏幕
- 敌人 AI：随机巡逻 + 概率性向基地方向进攻
